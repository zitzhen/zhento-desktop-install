帮助与支持

ZhenTo 官方文档与支持可在线查阅：zitzhen.cn，也可通过边栏（dock）中的帮助图标访问。

ZhenTo 基于 Ubuntu 构建，可使用 Ubuntu Discourse 与 Ask Ubuntu 等上游社区资源；问题反馈请提交至 GitHub Issues。

如需企业级支持，可订阅 Ubuntu Pro，获得 Canonical 提供的商业支持与更广泛的安全更新。
