Help and support

Official ZhenTo documentation and support are available at zitzhen.cn and via the Help icon in the dock.

ZhenTo is built on Ubuntu, so you can also use upstream resources such as Ubuntu Discourse and Ask Ubuntu. Please report ZhenTo issues on GitHub.

For enterprise users, an Ubuntu Pro subscription provides commercial support from Canonical and security updates for a wider range of packages.
